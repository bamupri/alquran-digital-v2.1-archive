Saya ingin tetap mempertahankan struktur navigasi, susunan teks, tata letak bab/halaman asli, serta fungsionalitas indeks yang ada pada versi CHM-nya agar esensi aplikasi aslinya tidak hilang.

***🇺🇸🇬🇧 English***

Hello everyone,

I am currently planning a digitalization and modernization project for a legacy desktop application called **Al-Quran Digital v2.1** (originally released by the Al-Quran compilation team back in August 2004 / Jumada al-Akhir 1425 H).

The original application is built on the **.CHM (Compiled HTML Help)** format, which internally contains a structure of individual `.htm`/`.html` files. My main goal is to convert the entire content and functionality of this CHM file into a modern, responsive website that anyone can access online.

## ⚠️ Important Note on Language & Content

Please note that the application's interface, navigation, and translations are entirely in Indonesian (Bahasa Indonesia), alongside the original Arabic Quranic text. Because it contains sacred text, preserving the exact layout, alignment, and formatting during the migration is highly critical to avoid any misinterpretation.

## Project Concept & Requirements

### Modern UI/UX
Revamping the outdated desktop interface into a clean, modern, and mobile-friendly web design.

### Preserving Original Structure
I want to maintain the original navigation tree, chapter/page hierarchy, and index system from the CHM version so that the essence and familiarity of the original app are preserved.

## The Challenges I Am Facing

Due to my limited technical background, I am struggling with how to properly decompile/extract the source files from the CHM, restructure those hundreds of `.htm` files into a cohesive web architecture, and apply modern styling (via CSS or modern web frameworks) without messing up the existing text alignment.
